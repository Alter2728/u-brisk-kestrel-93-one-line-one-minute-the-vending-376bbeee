One original pickup line, spoken by a vending machine to a passing human — in the machine's own world of exact change, the B4 button, the glass, and the drop, with the punch landing on the last words.

> "You don't need exact change — just press B4. I've been saving my best snack behind this glass all day, waiting for someone worth dropping for."

## Run it

```sh
python3 main.py
```

Writes the single line (142 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3 standard library only, fully deterministic.
